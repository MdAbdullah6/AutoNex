Excited to share my latest desktop project: AutoNex Smart Manager!

Over the past few weeks, I designed and built AutoNex Smart Manager, a C# Windows Forms application that simplifies daily task management and administrative workflows.

To make tracking tasks intuitive, I incorporated a Kanban-inspired board model. This lets users visually move tasks through stages of completion while managing records through custom forms (`AddTaskForm` and `MainForm`).

Key Highlights:
🔹 Built a responsive Graphical User Interface (GUI) using C# and WinForms
🔹 Implemented a Kanban-style task tracking model to improve workflow visibility
🔹 Designed multi-form navigation and managed custom application configurations (`App.config`)
